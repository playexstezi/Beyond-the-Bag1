 # Beyond the Bag

Minecraft Java 1.20.1 · Forge 47.2.0 · Java 17 · Русский язык.

Сборка: `gradle build --no-daemon`. Артефакт ожидается в `build/libs`.

## Состояние разработки
Это начальный технический каркас, а не готовый мод 1.0.0. Сейчас добавлены Forge-проект, регистрация предмета «Мешок измерений», русская локализация, модель-плейсхолдер, рецепт и workflow сборки.

Пока НЕ реализованы: измерения и телепортация, GUI, сохранение точки входа, персональные миры и права доступа, лабиринт/сброс вылазок, аномалии, существа и босс. Текстура предмета также требует отдельного художественного ресурса.
